# Dokumentacja Zmian: Dodanie pliku README.md

## 1. Zakres Zmiany
Utworzono plik `README.md` w głównym katalogu projektu, zawierający kompleksową dokumentację aplikacji **Lumina AI**.

## 2. Zawartość Dokumentacji
- Przegląd funkcjonalności: hybrydowy generator obrazów AI (Cloud Flux + Gemini Pro), ulepszanie promptów, wybór rozdzielczości 1K/2K/4K, presety artystyczne, eksport do systemowej galerii Androida (`MediaStore`) oraz lokalna galeria Room z ulubionymi i udostępnianiem.
- Opis architektury Clean Architecture, podziału pakietów (`domain`, `data`, `ui`) oraz realizacji zasad SOLID.
- Wymagania systemowe, stos technologiczny (Kotlin, Jetpack Compose, Room, OkHttp, Coil, Firebase AI Logic).
- Instrukcja konfiguracji, kompilacji oraz uruchamiania testów jednostkowych.
